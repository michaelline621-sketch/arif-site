# เว็บ ARIF SALAFI เวอร์ชันใหม่ (รวมห้องสมุด)

เปิดดูได้ทันทีโดยไม่ต้องตั้งค่าอะไร เว็บใช้ข้อมูลสำรองที่ฝังไว้ (ตอน ON LIFE TIME 21 ตอน ซีรีส์ คลิปสั้นตัวอย่าง หนังสือ) แล้วค่อยต่อกับชีตและช่องทางอื่นทีละอย่าง

## โครงสร้าง
- `index.html` หน้าแรก: ค้นหา รายการ คลิปสั้น ตอนล่าสุด ซีรีส์ หนังสือ ห้องสมุด สมัครรับข่าว
- ห้องสมุด: **ปิดไว้ก่อน** เอาออกจากเว็บชุดนี้ (ไม่มีลิงก์ ไม่มีการ์ด ไม่มีในผลค้นหา) เก็บโฟลเดอร์เดิมไว้ใน library-archived เปิดใหม่ได้โดยวางโฟลเดอร์ `library/` กลับมาข้างๆ index.html แล้วตั้ง `SHOW_LIBRARY: true` ใน config.js (ต้องเติมลิงก์ห้องสมุดกลับในหน้าสนับสนุนและนโยบายความเป็นส่วนตัวด้วย) ส่วนหนังสือของอารีฟยังอยู่ครบ
- `support.html` หน้าสนับสนุน ข้อมูลล้วน ไม่มียอด ไม่มีสลิป ไม่มีฟอร์ม
- `privacy.html` นโยบายความเป็นส่วนตัว (ฉบับร่าง ให้ผู้รู้ PDPA ตรวจก่อนเปิดใช้)
- `config.js` ตั้งค่าทั้งเว็บที่ไฟล์เดียว
- `Subscribe.gs` ตัวรับรายชื่อสมาชิกข่าว (ข้อ 3)

## ขึ้นเว็บ
ลากโฟลเดอร์นี้ทั้งโฟลเดอร์ไปวางบน Netlify (ลากทั้งโฟลเดอร์ทุกครั้ง ทั้งเว็บหลักและห้องสมุดอยู่ในโฟลเดอร์เดียวกัน) ลิงก์แชร์เล่มของห้องสมุดเดิม (`?book=B012`) จะเปลี่ยนเป็น `/library/?book=B012` ถ้าเว็บห้องสมุดเดิมอยู่โดเมนอื่น ให้คงไว้ก่อน แล้วค่อยย้ายเมื่อพร้อม

## ต่อระบบทีละอย่าง (แก้ใน config.js)
1. **ชีตข้อมูลเว็บ** (ตอน รายการ ซีรีส์ คลิปสั้น หนังสือ): ทำตามไฟล์ใน data-layer (ชีต v2 + Arif-YouTube-Sync.gs) แล้ววางลิงก์ชีตที่ `SHEET_ID` ชีตต้องแชร์ ทุกคนที่มีลิงก์ ผู้ดู ถ้าเว็บอ่านไม่ได้จะกลับไปใช้ข้อมูลสำรอง
2. **ลิงก์โซเชียล**: ใส่ที่แท็บ ตั้งค่า ของชีต (youtube, facebook, instagram, tiktok) ปุ่ม "ติดตามช่อง YouTube" ด้านบนจะใช้ค่า youtube
3. **สมัครรับข่าวด้วยบัญชี Google** (ฟรี ใช้เวลาราว 15 นาที):
   - สร้างโปรเจกต์ใน console.cloud.google.com > OAuth consent screen (External, ขอเฉพาะ email/profile/openid, กด Publish) > Credentials > OAuth client ID ชนิด Web ใส่ Authorized JavaScript origins เป็นโดเมนเว็บจริง คัดลอก Client ID ไปใส่ `GOOGLE_CLIENT_ID`
   - สร้างชีตใหม่ **ส่วนตัว (ไม่แชร์)** สำหรับเก็บรายชื่อ ห้ามใช้ชีตข้อมูลเว็บ เพราะแชร์เป็นสาธารณะ
   - ที่ script.google.com สร้างโครงการใหม่ วาง `Subscribe.gs` ใส่ `SHEET_ID` (ชีตส่วนตัว) กับ `CLIENT_ID` กด Run ฟังก์ชัน `setup` อนุญาตสิทธิ์ แล้ว Deploy เป็น Web app (Execute as: Me, Who has access: Anyone) คัดลอกลิงก์ /exec ไปใส่ `SUBSCRIBE_ENDPOINT`
   - ปุ่มนี้เก็บเฉพาะอีเมลกับชื่อ ไม่ได้ส่งอีเมลหาใคร ต้องส่งข่าวเองหรือผ่านบริการจดหมายข่าว
4. **หน้าสนับสนุน**: ใส่ `PROMPTPAY_ID` (แนะนำเบอร์มือถือ ไม่ใช้เลขบัตรประชาชน), `DONATE_BTC`, `DONATE_LN` ช่องที่ว่างจะไม่แสดง
5. **ปุ่มสมัครทำงานเมื่อไร**: เมื่อใส่ทั้ง `GOOGLE_CLIENT_ID` และ `SUBSCRIBE_ENDPOINT` ก่อนหน้านั้นปุ่มขึ้นว่า จะเปิดเร็ว ๆ นี้

## รอบล่าสุด (อ่านก่อน)
- ชื่อ ARIF SALAFI (แถบบน หน้าสนับสนุน นโยบายความเป็นส่วนตัว และตัวอักษรใหญ่หลังรูป) เป็น Times New Roman สีขาว ถ้าเครื่องไม่มี Times New Roman จะใช้ Times หรือ Liberation Serif แทน หน้าตาใกล้เคียงกัน
- กล่องลอยหน้าแรกมีไอคอนเล็ก: หมุด = แนะนำ (ปักหมุด) ดาว = ยอดนิยมประจำสัปดาห์ กล่องสุ่มไม่มีไอคอน
- ส่วน "คำถามที่ตอบแล้ว" บนหน้าแรกเลือกปักหมุดก่อน แล้วเลือกจากคนละตอน ไม่ให้ซ้ำตอนเดียวกันทั้งหมด หน้า `#answers` แสดงทีละ 60 ข้อ มีปุ่มแสดงเพิ่ม
- ชีต: วางสคริปต์ใหม่แล้วกดเมนู **จัดระเบียบชีต** (ดูใน README ของ data-layer) เพื่อลบแท็บและคอลัมน์ที่ไม่ใช้ เพิ่มคอลัมน์ที่ขาด และจัดเรียง

## เวอร์ชันก่อนหน้าเพิ่มอะไร
- **โลโก้ใหม่** (AS) ในแถบบน ส่วนท้าย (แบบมีแบนเนอร์ SINCE 2019) และไอคอนแท็บ รูปคุณอารีฟใช้ภาพอัปสเกลที่ตัดพื้นหลังใหม่ให้คมขึ้น
- **กล่องลอยหน้าแรก** กดแล้วเล่นคลิป เลือก 6 กล่อง = ปักหมุด 3 + ยอดนิยมประจำสัปดาห์ 2 + สุ่ม 1 (ปักหมุดที่ช่อง ปักหมุดหน้าแรก ใส่ ใช่ ในแท็บ จุดตอบ หรือ คลิปสั้น) ถ้าไม่ครบจะเติมจากที่เหลือ
- **คลิปสั้นทั้งหมด:** หน้าแรกแสดง 30 คลิป ปุ่ม "คลิปสั้นทั้งหมด" เปิดหน้า `#clips` แสดงแถวต่อหมวด (หมวดละ 12 คลิป + ปุ่มดูทั้งหมดในหมวด) และตารางแบ่งหน้า 24 ใบต่อหน้า ลิงก์แต่ละหมวดและหน้าแชร์ได้ เช่น `#clips=หมวด&p=2` ช่องค้นหาค้นเจอทุกคลิป
- **สรุป 1–5 ประโยค:** คอลัมน์ สรุป + สถานะสรุป (แท็บ คลิปสั้น, ตอน) และ สรุปสั้น (แท็บ จุดตอบ) แสดงใต้ตัวเล่นและในผลค้นหา เฉพาะแถวที่สถานะสรุปเป็น ตรวจแล้ว (คลิปสั้น/ตอน) หรือแถวจุดตอบที่สถานะ แสดง/ว่าง
- ถ้าชีตเดิมยังไม่มีคอลัมน์ใหม่เหล่านี้ เว็บยังทำงานได้ ส่วนนั้นจะว่างจนกว่าจะเพิ่มคอลัมน์ตามชีต v2

## เฟส 1: ค้นเจอทันทีพร้อมนาทีในคลิป
- **ค้นหาเต็มจอ:** ปุ่ม "ถามคำถามที่ค้างใจ" หรือ "ค้นหา" ในแถบบน หรือกด `/` (Ctrl/⌘+K) พิมพ์แล้วเห็นผลทันที แยกเป็น คำตอบในคลิป / ตอน / คลิปสั้น / ซีรีส์ / หนังสือ / ห้องสมุด มีตัวกรองหมวด ค้นด้วยคำพ้อง แก้คำอังกฤษสะกดผิดเล็กน้อย และพิมพ์เป็นประโยคได้ (ไม่ใช้ AI)
- **คำถามที่ตอบแล้ว:** ส่วนใหม่บนหน้าแรก และหน้า `#answers` ข้อมูลมาจากแท็บ **จุดตอบ** ในชีต (คำถาม + รหัสวิดีโอ + เวลาเริ่ม + สรุปสั้น) กดแล้วเล่นตั้งแต่นาทีนั้น ถ้ายังไม่มีแถวในแท็บนี้ ส่วนนี้จะซ่อนเอง
- ต้องใช้ชีต v2 ล่าสุด (มีแท็บ จุดตอบ และ คำพ้อง) ถ้าชีตเดิมยังไม่มีแท็บเหล่านี้ เว็บใช้งานได้ตามปกติ แค่ยังไม่มีส่วนคำตอบ
- เริ่มเติมจากตอนที่คนดูเยอะ 20–30 จุดแรก ใช้เมนูในชีต "ร่างจุดตอบจากช่วงเวลา (chapters) ในคำอธิบายคลิป" ช่วยร่างได้ถ้าคำอธิบายคลิปบน YouTube มีช่วงเวลา

## ที่ยังต้องทำเอง
- ลิงก์ EVERY-TIME: รหัสเพลย์ลิสต์ที่ส่งมา (PLQPfLTZQIOPM) สั้นผิดปกติ ตรวจในแท็บ บันทึกการซิงก์ หลังรันซิงก์ครั้งแรก
- คลิปสั้นทั้ง 8 รายการเป็นตัวอย่าง ยังไม่มีลิงก์ จึงยังไม่มีภาพ ใส่แหล่งคลิปสั้นในแท็บ ตั้งค่า (เพลย์ลิสต์ Shorts หรือ @ช่อง) แล้วรันซิงก์ ภาพมาจาก YouTube เอง
- เสาหลัก/ระดับของซีรีส์เป็นร่างจากเว็บเดิม ให้คุณอารีฟตรวจ
- ช่องข้อมูลที่ต้องกรอกจริง: ลิงก์เพลย์ลิสต์ของซีรีส์ทั้ง 24 รายการ

## ที่ทดสอบแล้ว และที่ยังไม่ได้ทดสอบ
ทดสอบในเบราว์เซอร์จำลอง: หน้าแรก (ข้อมูลสำรอง) ค้นหา มุมมองรายการ ตัวเล่นวิดีโอ Path Finder หน้าสนับสนุน ห้องสมุด (เส้นทางคำถาม ดูทั้งหมด ชั้นสุ่ม) และมือถือ 390px ยังไม่ได้ทดสอบกับ YouTube จริง Google Sign-In จริง และชีตจริง


## สรุปคำตอบและ SEO prerender

หน้าคำตอบ (`/answers/`) มีเนื้อหาสรุปใน HTML ตั้งแต่ต้นทางเพื่อให้ค้นหาและแชร์ได้ แม้ก่อน JavaScript โหลดเสร็จ หากต้องสร้างข้อมูลชุดใหม่ ให้ทำตามลำดับนี้จากโฟลเดอร์ workspace ที่มีไฟล์ `summarize_answers.py`, `build_answer_seo.py`, `tag_answers.py` และโฟลเดอร์ `arif-site-v2` อยู่ร่วมระดับกัน:

1. รัน `python3 summarize_answers.py --resume --workers 3` เพื่อวิเคราะห์วิดีโอตามรหัสและเวลา สคริปต์แบ่งคำขอไม่เกิน 60 จุดต่อชุด เก็บผลดิบไว้ใน `answer-summaries/raw/` และผลที่จับคู่แถว/เวลาแล้วไว้ใน `answer-summaries/summaries.json` อย่าแก้หรือลบผลดิบก่อนตรวจชุดให้ครบ
2. เมื่อผลตรวจครบทุกแถวแล้ว รัน `python3 build_answer_seo.py --dry-run` เพื่อตรวจจำนวนและรหัส/เวลา จากนั้นรัน `python3 build_answer_seo.py` เพื่อเติมคอลัมน์ “สรุปสั้น” ใน Excel, สร้างข้อมูลสำรองใน `data-fallback.js` และ prerender รายการสรุปลง `/answers/index.html` ระบบเก็บสำเนา Excel ก่อนแก้ไว้ใน `../backups/`
3. ทดสอบหน้าเว็บและเปิดดู source ของ `/answers/` ว่ามีหัวข้อ สรุป และลิงก์ YouTube พร้อมเวลา ก่อนอัปโหลดโฟลเดอร์เว็บทั้งชุดไป Netlify

สรุปเหล่านี้เป็นข้อความที่ AI สร้างจากเนื้อหาวิดีโอเพื่อช่วยค้นหา ไม่ใช่คำถอดเสียง และยังควรผ่านการตรวจทานโดยทีมก่อนนำไปใช้อ้างอิงเป็นคำพูดตรง ๆ เมื่อเชื่อม Google Sheet ไว้ เว็บจะใช้ข้อมูลจากชีตก่อน และดึงสรุปจาก fallback มาเติมเฉพาะแถวที่ชีตยังไม่มีสรุป โดยไม่เขียนทับสรุปที่ทีมกรอกไว้แล้ว


## หัวข้อสำหรับแต่ละจุดตอบ

คอลัมน์ “หัวข้อ” ใช้ชุดหัวข้อควบคุมเดียวกัน 21 หัวข้อ และกำหนด 1–2 หัวข้อต่อจุด เพื่อให้ tag บนการ์ดและตัวกรองหน้า `/answers/` สม่ำเสมอ หากต้องจัดใหม่หลังเปลี่ยนคำถามหรือสรุป ให้รันจากโฟลเดอร์ workspace ที่มี `tag_answers.py` และ `arif-site-v2` อยู่ร่วมระดับกัน:

1. `python3 tag_answers.py --pilot` ทดลองกับ 30 จุดที่กระจายตามคลิป เพื่อดูความเหมาะสมของหัวข้อ
2. `python3 tag_answers.py --all --resume --workers 3` สร้างหัวข้อครบ 787 จุดและเก็บผลไว้ที่ `answer-summaries/topic-results.json` (รันซ้ำได้เพื่อทำต่อเฉพาะรายการที่ยังขาด)
3. `python3 tag_answers.py --apply` เขียนหัวข้อใน Excel แล้วสร้าง `data-fallback.js`, หน้า `/answers/` ที่มีหัวข้อใน HTML, CSV ตรวจทาน และรายงาน QA ใหม่ โดยเก็บสำเนา Excel ก่อนเพิ่มหัวข้อใน `../backups/`

หัวข้อสร้างด้วย AI จากคำถามและสรุปสั้น จึงควรตรวจรายการที่ระบุความมั่นใจต่ำก่อนใช้เป็นการจำแนกอย่างเป็นทางการ
